# Little Learners

A responsive website for a children's learning academy, built with React, TypeScript, and Vite.

## Features

- Responsive design for desktop, laptop, and mobile.
- Hero section introducing the academy.
- Benefits and testimonials sections.
- Frequently Asked Questions (FAQ).
- Navigation cards and footer.
- Add Home,About and Academics pages to the site.
- Use react-router-dom to navigate between pages.

## Technologies

- React
- TypeScript
- Vite
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hassan-abboud-3330/task-2.git
```

### 2. Navigate to the project directory

```bash
cd academy-landing-page
```

### 3. Install dependencies

```bash
pnpm install
```

### 4. Start the development server

```bash
pnpm run dev
```
